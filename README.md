# Don Studio Engine

Локальный desktop-движок для обучения программированию с упором на **Python** и **C++**.

## Что это

`Don Studio Engine` — это учебная IDE-подобная программа в одном окне (в стиле VS Code):

- вкладки **Python** и **C++**;
- встроенный редактор кода;
- запуск Python-скриптов;
- сборка и запуск C++ (`g++`);
- отдельная панель лога/консоли;
- современная тёмная тема.

## Для кого

Проект сделан для новичка:

- можно быстро начать писать код;
- не нужно поднимать веб-сервер;
- всё работает как обычное desktop-окно.

## Быстрый старт

```bash
python3 app.py
```

## Требования

- Python 3.10+
- для C++: установленный `g++` в PATH

## Возможности на будущее

- подсветка синтаксиса;
- автосохранение проектов;
- встроенные учебные шаблоны;
- запуск других языков/движков генерации.
