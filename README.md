# Don Studio Engine

Локальный desktop-движок для обучения программированию с упором на **Python** и **C++**.

## Что это

`Don Studio Engine` — это учебная IDE-подобная программа в одном окне (в стиле VS Code):

- вкладки **Python** и **C++**;
- встроенный редактор кода;
- запуск Python-скриптов;
- сборка и запуск C++ (`g++`);
- отдельная панель лога/консоли;
- современная тёмная тема.

## Для кого

Проект сделан для новичка:

- можно быстро начать писать код;
- не нужно поднимать веб-сервер;
- всё работает как обычное desktop-окно.

## Установка

### 1) Скачай проект

Если у тебя есть `git`:

```bash
git clone <URL_ТВОЕГО_РЕПО>
cd Don
```

Или просто скачай ZIP архива репозитория и распакуй его в папку `Don`.

### 2) Установи Python

Нужен **Python 3.10+**.

Проверка:

```bash
python3 --version
```

> На Windows может быть команда `python --version`.

### 3) Установи C++ компилятор (для вкладки C++)

Нужен `g++` в PATH.

Проверка:

```bash
g++ --version
```

Если не установлен:

- **Ubuntu/Debian**:
  ```bash
  sudo apt update
  sudo apt install -y g++
  ```
- **Windows**: установи MinGW-w64 или MSYS2 и добавь `g++` в PATH.
- **macOS**:
  ```bash
  xcode-select --install
  ```

### 4) Запусти приложение

Из папки проекта:

```bash
python3 app.py
```

> На Windows: `python app.py`

## Быстрый старт

1. Открой вкладку **Python** или **C++**.
2. Напиши код (или используй шаблон, который уже вставлен).
3. Нажми кнопку **«▶ Запустить текущий код»**.
4. Смотри результат в блоке **«Консоль / Логи»**.

## Требования

- Python 3.10+
- `tkinter` (обычно уже в составе Python)
- для C++: установленный `g++` в PATH

## Как опубликовать проект на GitHub

Я не могу напрямую загрузить в твой GitHub-аккаунт без твоей авторизации, но вот быстрые шаги:

### 1) Создай пустой репозиторий на GitHub

- Открой GitHub → **New repository**
- Назови его, например: `don-studio-engine`
- Не добавляй `README`/`.gitignore` (так проще связать с локальным проектом)

### 2) Привяжи локальный проект к GitHub

В папке проекта выполни:

```bash
git remote add origin https://github.com/<ТВОЙ_ЛОГИН>/don-studio-engine.git
```

Проверь:

```bash
git remote -v
```

### 3) Отправь код

```bash
git push -u origin work
```

> Если у тебя основная ветка называется `main`, используй `main` вместо `work`.

### 4) Если GitHub просит авторизацию

- Используй вход через браузер (Git Credential Manager), или
- Создай **Personal Access Token (PAT)** и используй его как пароль.

После этого проект будет опубликован, и ты сможешь скинуть ссылку на репозиторий.
